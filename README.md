# Лабораторна: мережеві утиліти, bash-скрипт, логи Apache

1. Натисніть **Use this template** і створіть свій репозиторій.
2. Відредагуйте `config.env` (прізвище, ім'я, група, дата, email).
3. Покладіть Apache-лог у `logs/` (ім'я має збігатися з `LOGFILE`).
4. Запустіть `bash lab.sh`.
5. Заповніть `report/REPORT.md`, зробіть commit і push.
6. У вкладці **Actions** має бути зелена галочка. Посилання на репозиторій додайте у звіт.

## Структура, яку створює `lab.sh`
```
Прізвище/
├── DEE/
│   └── Ім'я.txt        (email)
├── SEE/
└── SSS/
    └── Прізвище.txt    (група і дата)
```
Файли також копіюються в `Прізвище/`.
